noir study - PWAファイル

公開方法（GitHub Pages）:
1. GitHubで新しいPublicリポジトリを作成（例: noir-study）。
2. このZIPを解凍し、index.html / manifest.json / icon.svg / sw.js をリポジトリ直下にアップロード。
3. リポジトリの Settings → Pages → Build and deployment で Deploy from a branch を選択。
4. Branch: main、Folder: /(root) を選んで Save。
5. 公開完了後、Settings → Pages に表示されるURLをChromeで開く。
6. AndroidのChrome右上「⋮」→「アプリをインストール」または「ホーム画面に追加」→追加。

注意: GitHub Pagesのサイトは公開URLで誰でも閲覧できます。勉強予定や記録は端末のブラウザ内に保存され、別端末とは同期されません。ブラウザデータを消すと記録が消えることがあります。GitHub Pagesの公開反映には数分かかることがあります。
